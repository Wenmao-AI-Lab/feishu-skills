# 飞书所有权转移
**一个专为 AI 智能体设计的技能，一句话定位：**

转移飞书文档/多维表格的所有权给指定用户。触发场景：(1) 使用 feishu_doc 创建文档后自动转移所有权；(2) 用户说"把权限给我"或要求转移文档所有权时；(3) 使用 feishu_bitable_create_app 创建多维表格后。支持 docx / bitable / sheet / doc / file / wiki / slides 等所有飞书文档类型。


【安装方式】（三步安装 · 复制文件夹即用）
  只需三步，即可把本技能装进AI对话框直接使用：

  第1步｜复制技能文件夹：找到本技能所在的文件夹，
       右键 → 复制路径（或直接复制整个文件夹）。

  第2步｜放入智能体对话框：把复制好的文件夹路径粘贴到对话框里
       （也可以直接把文件夹拖进对话框输入框，和发图片一样）。

  第3步｜输入安装指令，把下面这句话粘贴发送：

  【请解压这个技能包「飞书所有权转移」，并安装到技能目录，
  完成后告诉我，后续对话我会直接使用它。】

  · 等AI回复"安装完成"即可正常使用。
  · 多个技能一起安装：把多个文件夹路径/文件夹一起放入对话框，
    再发送："请把上面这些技能包全部解压安装"。
  · 安装后直接描述需求，AI会自动调用本技能。
