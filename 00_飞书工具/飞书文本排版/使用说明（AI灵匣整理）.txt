# 飞书对话排版

把任意内容转成**飞书聊天可直接复制发送**的纯文本。目标是手机端扫一眼舒服，不是云文档排版。

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

## 两种输出模式

调用本 skill 时按触发词判断模式，**未指定默认 -F**。

| 模式 | 触发词 | 处理方式 |
|------|--------|----------|
| F 全文（默认） | 「优化排版」「排版」「优化排版-F」「排版-F」 | 保留全部信息，只改排版与层次，不删内容 |
| D 摘要 | 「优化排版-D」「排版-D」 | 选取约 60% 的核心内容输出，砍掉低价值段落 |

「-D 怎么选 60%」

- 保留：结论、关键数据、行动建议、金句
- 删除：重复论据、铺垫背景、过渡废话、次要案例
- 不是“每段缩水 40%”，而是“砍掉 40% 的低价值段落，剩下的原样保留”

额外档位：用户明确要「超短/几句话/随手发」时，压缩到 80–150 字，无视 F/D。

## 语言模式判断（中文 / 英文）

- 用户也可显式说「按英文排 / 按中文排」覆盖自动判断

### 1. 段间空行，段内不强制换行

- 不同意群之间空一行，这是唯一的“换行”手段
- **句中绝不换行**：逗号、顿号、没写完的半句话，绝不能在这里被断开；一行必须落在一个完整句子的句号/问号/感叹号上
- **段落不要太长**：平均每段 3 句左右；一段超过 4–5 句就按意群拆成两段，拆段处空一行（拆段不是断句）
- 整篇要有“呼吸感”：段间留白 + 每段 3 句，让手机端扫读不压抑、不觉得是一堵字墙
- 不指望加粗、引用、标题样式在对话里自动显示

**英文版补充**（主体为英文时生效）：

- **何为“一句”**：只有 `.` `?` `!` 后紧跟**空格 + 大写字母**（或换行、文末）才算句末；点后是小写、或仍是同一意群，就**不是**句末。这样缩写（`e.g.` `i.e.` `etc.` `vs.` `Mr.` `Dr.` `U.S.` `et al.` `a.m.` `Inc.`）、小数（`3.14` `0.5`）、网址/邮箱里的点，才不会被误判成换行点。
- **每段更短**：英文单句长，每段 **1–3 句**为标准（硬上限 4 句）；单段软上限**约 50 词**，超出按意群拆段。
- **长句拆短（英文独有）**：单句超过约 25 词（手机约两行）时，在连词（`and / but / because / which`）、分号、em dash 处断成两句。这一步是英文呼吸感的关键，中文不需要。

### 2. 符号做层次

用纯文本符号替代 Markdown：

| 用途 | 用这个 | 不要用 |
|------|--------|--------|
| 总标题 | `【标题】` | `#` `**标题**` |
| 小节标题 | `■ 小节名` | `##` `###` |
| 列表项 | `· 内容` 或 `1. 内容` | `-` `*` 嵌套列表 |
| 金句/引用 | `「金句内容」` 独立成段 | `>` 引用块 |
| 分隔收尾 | `——` 单独一行 | `---` |

**英文版补充**：英文沿用同一套符号，只把语言相关的本地化——

| 用途 | 英文用 | 不用 |
|------|--------|------|
| 总标题 | `【Title】`（Title Case） | `#` `**` |
| 小节 | `■ Section`（首字母大写） | `##` |
| 列表项 | `· item`（句末不加句号，全篇统一） | `-` `*` |
| 金句/强调 | `"quote"` 独立成段 | `>` `「」` |
| 收尾分隔 | `—`（em dash）单独一行 | `---` `——` |

- em dash `—` 在英文里是合法句内标点，**允许句内插入**（与中文「禁段内 ——」不同）；但它不做层次分隔，层次仍靠空行 + `■`。

### 3. 剥离 Markdown

输入含 Markdown 时**全部转换**，原样保留 `**` `>` `#` 视为失败：

- `**粗体**` → 去掉星号，必要时用 `「」` 强调
- `> 引用` → 改为 `「引用内容」` 独立段
- `# 标题` → `【标题】`
- `## 标题` → `■ 标题`
- 表格 → 改为 `·` 列表或「键：值」行

### 4. 聊天体精简（仅 -D 生效）

- -F 模式：全文保留，不动内容
- -D 模式：删冗余背景，保结论、关键数据、行动建议（具体见上方「两种输出模式」）
- 禁止在正文使用破折号（——）作句内连接；仅允许收尾分隔线用 `——`
- 英文例外：em dash `—` 可作句内插入（见 §2），不受上条限制；英文收尾分隔线用 `—` 而非 `——`
