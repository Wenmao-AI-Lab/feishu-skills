◆ 1.1 方法一：全部一起装（推荐，一次搞定）

┌────────────────────────────────────────────────────────────┐

│ 第2步：把 zip 文件全部拖进 AI 对话框（可以多选，和发图片一样）
│ 第3步：复制下面这句话发送：
│
│ 请把上面这些技能包全部解压安装，安装完成后告诉我，后续对话我会直接使用它们。

│ 第4步：等 AI 回复"安装完成"，全部技能就位 ✅

◆ 1.3 怎么确认装好了？

┌────────────────────────────────────────────────────────────┐
│ ✅ AI 明确回复"安装完成"
│ ✅ 发一句"帮我做飞书相关的事"，AI 开始正常响应

◆ 3.0 先学会：怎么把一个复杂想法说清楚？

┌────────────────────────────────────────────────────────────────────┐
│ 下面的"直接说需求"都是单句简单话术，够用但只是起步。
│ 真实使用中，你的需求往往更复杂——没关系，用下面这个万能公式，AI 会自动拆解执行：
└────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────┐
│ 万能公式：背景/对象 + 要做什么 + 具体要求 + 输出格式
└──────────────────────────────────────────────────┘

│ 新手口语（AI 也能听懂） │ 结构化表达（效果更精准） │
┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
│ "帮我看看怎么做" │ "帮我做【具体对象】的【动作】，要求【条件】，输出【格式】" │

┌──────────────────────────────────────────────────────────────────────┐
│ 💡 记住：复杂需求 = 一条条说（不用一次说全）。先给个大概想法 → AI 出结果 → 你再追加修改，效果最好。

│ Q2：为什么 AI 没反应 / 说听不懂？
│ 三步排查：①确认技能已安装 ②描述够具体（做什么 + 对象 + 要求）③确认是否需要 API Key（🟡类技能 AI 会引导配置）。
│
│ Q3：需要先学专业知识才能用吗？
│ 不需要！技能是"AI 替你干活"，你只要会描述需求就行。遇到专业细节直接问 AI，它会按最佳实践帮你处理。
│
│ Q4：效果不满意怎么办？
│ 不用重来，直接描述修改点，AI 会在上次基础上迭代。比如"再详细一点""换个风格""加上数据"。
│
│ Q5：哪些技能要花钱 / 要配置？
│ 见第0章门槛表：🟡 需配置的是要 API Key 的平台类技能（AI 会引导申请）；🔴 需软件的是要本机装工具；🟢 零门槛直接用。
│
│ Q6：技能装多了会拖慢 AI 吗？
│ 不会。技能按需加载，只在提到相关内容时调用。
│
│ Q7：我不知道怎么描述需求 / 怕说错？
│ 完全不用担心！发个大概想法就行，比如"帮我看下这个""帮我写个东西"——AI 会主动追问澄清，一步步帮你把需求问清楚。
│
│ Q8：一次想做好几件事，怎么说？
│ 两种方式都行：① 一句话串起来，比如"先分析数据，再出报告"，AI 会拆解成步骤挨个完成；② 一条条说，推荐第②种。

│ Q9：我是做飞书的，重点用哪几个？
